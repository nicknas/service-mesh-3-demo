Ficheros:

* link:../README.adoc#operators-olm[README.adoc — Operadores OLM]: inventario de operadores, versiones CSV y orden de instalación.
* *demo-guion-observabilidad.md:* guión de demo (métricas y trazabilidad en consola OpenShift, ~20 min).
* *demo-metrics-cheat-sheet.md:* cheat sheet con queries PromQL para *Observe → Metrics* (correlacionadas con Kiali).
* *setup-dynatrace-saas-bbgmb.sh:* activa Dynatrace **SaaS** en cluster-bbgmb (fan-out OTel → Tempo + Dynatrace). Requiere `DT_ENV_ID` y `DT_API_TOKEN` de un tenant `*.live.dynatrace.com`.
* *deploy-dynatrace-cluster-bbgmb.sh:* _(solo clusters BBVA con red interna)_ Dynatrace Managed tipo aso1.
* *generate-traffic.sh:* genera tráfico usando el ingress. Hay que configurar el nombre de host en el propio script:
+
[source, bash]
----
HOSTNAME=bookinfo.apps.cluster-bbgmb.dyn.redhatworkshops.io
----

* *Directorio 'internal-traffic':* contiene un Dockerfile para crear una imagen que llama a dos endpoints de la aplicación bookinfo usando los services. La idea es usar la imagen para desplegar un contenedor que genere tráfico continuamente desde dentro del cluster. Está basada en Alpine e incluye:
** curl
** netcat
** openssl
